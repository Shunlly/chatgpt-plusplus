# Dream Skin v2.0 主题创作功能总览

## 🎨 核心理念

**让每个用户都能成为主题创作者**

从零代码的可视化编辑，到深度定制的自定义效果类，Dream Skin v2.0 提供了完整的主题创作工具链。

---

## 📦 完整工具链

### 1️⃣ 可视化编辑器 `theme-editor.html`

**适合**: 所有用户，零代码  
**时间**: 5分钟创建一个主题

**功能**:
- ✅ 左右分屏：编辑 + 实时预览
- ✅ 所见即所得：拖动滑块立即看到效果
- ✅ 性能监控：实时 FPS + 质量等级显示
- ✅ 7种内置效果：particles, gradient, matrix-rain, starry-galaxy, aurora, breathing, cyberpunk-neon
- ✅ 完整配置界面：颜色选择器、滑块、开关
- ✅ 标签管理：添加/删除主题标签
- ✅ 一键导出：生成标准 JSON 格式
- ✅ 内置帮助：快速参考文档

**使用**:
```bash
open tweaks/dream-skin/theme-editor.html
```

---

### 2️⃣ JSON 模板 `THEME-TEMPLATE.json`

**适合**: 开发者，喜欢手写代码  
**时间**: 10分钟创建一个主题

**功能**:
- ✅ 标准 Schema v2 格式
- ✅ 完整字段说明（注释）
- ✅ customization 配置示例
- ✅ 开箱即用

**使用**:
```bash

# 编辑 my-theme.json
node theme-cli.js validate my-theme.json
node theme-cli.js install my-theme.json
```

### 4️⃣ CLI 管理工具 `theme-cli.js`

**适合**: 开发者，自动化工作流  
**功能**: 验证、安装、管理主题

**命令**:

```bash
# 验证主题格式
node theme-cli.js validate my-theme.json
# 输出: 错误、警告、建议

# 安装主题
node theme-cli.js install my-theme.json
# 自动: 创建目录、复制文件、更新 index.js

# 列出已安装主题
node theme-cli.js list
# 显示: ID、名称、版本、作者、类型、性能等级
```

**特性**:
- ✅ 严格验证：检查必需字段、类型、格式
- ✅ 友好提示：彩色输出，详细错误信息
- ✅ 自动化：一键安装，无需手动配置
- ✅ 安全检查：覆盖前确认，防止误操作

## 💡 最佳实践

### ✅ 推荐做法

1. **先原型，后优化** - 用编辑器快速试错，满意后导出优化
2. **重视性能** - 始终监控 FPS，适配不同设备
3. **提供配置** - 让用户能自定义颜色、速度等参数
4. **写好描述** - 清晰说明主题特点和使用场景
5. **测试交互** - 如果有鼠标/点击交互，多测试体验
6. **参考示例** - 查看内置主题的实现方式

### ❌ 避免

1. **过度复杂** - 不要在一个主题堆太多效果
2. **忽略性能** - 不要让 FPS 降到 30 以下
3. **硬编码** - 使用配置项而非固定值
4. **缺少文档** - 说明主题特点和交互方式
5. **盲目跟风** - 创作符合自己审美的主题
